# ⚔ Reino de Ceniza ⚔

*Dragones, castillos y un rey que no quiso morir.*

Servidor medieval de Minecraft **Java 1.20.1 con Forge 47.4.28**: Ice and Fire, L_Ender's Cataclysm,
castillos, catacumbas, Terralith, armaduras de caballero y una historia de 40 misiones para jugar en equipo.

## Descargar

Ve a **[Releases](../../releases/latest)** y baja uno de estos:

| Archivo | Para quién |
|---|---|
| `Reino-de-Ceniza-Windows.zip` | Windows con cualquier launcher (SKLauncher, TLauncher, el oficial…). Trae Java 17 y un instalador. |
| `reino-de-ceniza.mrpack` | Prism Launcher o la app de Modrinth (Windows, Linux o Mac): *Agregar instancia → Importar*. |

## Instalar en Windows

1. Abre tu launcher de Minecraft una vez y ciérralo.
2. Descomprime `Reino-de-Ceniza-Windows.zip` y haz doble clic en **`instalar.bat`**.
   Si Windows avisa: *Más información → Ejecutar de todas formas*.
3. En tu launcher elige el perfil **Reino de Ceniza** y dale a Jugar.
4. Multijugador → Agregar servidor → la dirección que te pase Ariel.

El instalador pone los mods en `%APPDATA%\.minecraft\instancias\reino-de-ceniza`, así que no toca tus otros mods.

## En el juego

- **M**: mapa · mirar un bloque o mob muestra su nombre y vida.
- Al entrar recibes el libro **Crónicas del Reino de Ceniza** con la historia y las misiones.
- **O**: shaders (vienen apagados). Complementary es el bonito; MakeUp Ultra Fast, para PC modestas.
- Si el servidor te rechaza, pide que te agreguen a la lista blanca.
